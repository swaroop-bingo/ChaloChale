# ✈️ ChaloChale – Travel & Tourism Website

**Explore More. Travel Better. Create Memories.**

ChaloChale is a responsive travel and tourism website designed to help users explore destinations, discover holiday packages, and plan their next adventure through an attractive and user-friendly interface.

The website provides destination browsing, package information, a booking interface, and user authentication pages.

---

## 🌍 Project Overview

ChaloChale aims to make travel discovery and trip planning easier by bringing travel destinations, holiday packages, and booking information together in one platform.

The website features a modern design, responsive layouts, interactive elements, and a consistent user experience across multiple pages.

## ✨ Features

- **Home Page:** Attractive landing page with travel inspiration and destination discovery.
- **Destinations:** Explore popular domestic and international destinations.
- **Travel Packages:** Browse holiday packages with prices, ratings, and duration.
- **Booking Page:** Enter travel details and view an estimated booking summary.
- **About Us:** Learn about the platform, its mission, and vision.
- **Contact Us:** Contact form and travel-related information.
- **Login Page:** User login interface with form validation.
- **Signup Page:** Account registration interface with password confirmation.
- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Interactive UI:** Navigation, search, filtering, password visibility, and form validation.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/swaroop-bingo/ChaloChale.git
```

### 2. Open the Project Folder

```bash
cd ChaloChale
```

### 3. Run the Website

Open `index.html` in your browser.

Alternatively, open the project in Visual Studio Code and use the **Live Server** extension.
